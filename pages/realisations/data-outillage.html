Folder Mapper

Création originale vérifiée

Outil CLI Rust qui reçoit un chemin de dossier, parcourt récursivement les fichiers et persiste les couples filename/filepath dans une table SQLite.[EU-DO-01]

Dépôt non forké ; 7 commits sur 7 attribués à RickOwri.[EU-DO-02]

RustSQLiteWalkDirrusqlite
Entrée bornéeUn unique chemin de dossier est exigé en argument CLI.
Structure expliciteSchéma minimal file_mappings(filename, filepath).
Persistance localeLa base 0_SQL_allfiles.db est ouverte ou créée dans le dossier cible.
InspectabilitéLe dépôt, le code source et l’historique de commits sont publics.

Ce que cela ne prouve pas : aucune architecture data de production, aucun index SQL, aucune idempotence, aucun ordre déterministe ni tolérance aux erreurs ne sont revendiqués. Le code public ne fournit pas ces preuves.[EU-DO-03]
