Consequences

The weak point is usually the exception, not the happy path.

The evidence chain breaks at the exception

A free-text correction can preserve a sentence while losing the applicable rule, actor, rationale and version.

Automation can hide the human decision

Faster execution is not enough if approval authority and exception handling become harder to reconstruct.

Snapshots do not reconstruct a process

Reproducibility requires ordered transformations and approved deviations, not only archived extracts.

Questions

Resolve the questions that change responsibility, not cosmetic FAQs.

Can this run on an ongoing study?

Yes, after the pipeline and exception model are bounded and replayed against a closed-study path. The current study is not used as the first uncontrolled test.

Does automation replace the data manager?

No. The target is to remove repetitive execution while making exceptions, approvals and accountability more explicit.

Do we need to change EDC?

No. EDC selection/migration is explicitly outside this mandate.

How are patient data handled?

Development should use test or appropriately pseudonymised data; execution remains inside the client-controlled environment and access model.
