Triggers

When the number is important enough to require a reconstruction path.

Two dashboards disagree

The committee resolves the conflict verbally because neither result carries sufficient source and rule context.

A correction bypasses the pipeline

The value is fixed, but the change is not part of the replayable execution history.

An audit asks “from where?”

The pipeline has changed since the reported period and the answer depends on a person.

A report has one human dependency

Only one operator knows which extraction, filters and manual steps produced the final metric.

Consequences

The gap is not more documentation. It is evidence missing from execution.

No attached provenance

A wiki can describe intended logic; it does not establish what produced a specific output instance.

Quality after publication

When the reader discovers the anomaly, the control is downstream of the decision.

Replay depends on memory

Inputs, parameters, corrections and code versions must be recoverable, not merely rerunnable.

Ownership fragments

Schema, transformations, controls and dashboard semantics can cross different accountable roles.

Workflow-provenance research models outputs as potentially depending on only a subset of inputs and on a module’s internal state, rather than assuming every output depends on every input.

Questions

Resolve the architecture decision before buying another platform.

Replace the warehouse or orchestrator?

Not by default. Inventory the existing stack first; replacement follows only from an unmet required property.

How many sources in the first slice?

Use a representative bounded slice, then prove that the team can extend the pattern. Heterogeneity and risk determine the number.

What if rules are undocumented?

Extract them from code and interviews, write them explicitly, and obtain accountable owner validation.

Does lineage slow pipelines?

Instrumentation can add metadata writes, storage and processing overhead. Measure representative runs; this page claims no universal percentage.
