# Copywriting — Evidence Unit Placement Registry

Ce dépôt matérialise les audits de copywriting reliés au graphe Neo4j.

Principe : `x = V + valeur + unité + population + période + source` → `X = f(x)` Evidence Unit bornée → `Y` séquence + buyer question + rôle NLP → `G = g(X,Y)` copy proposée.

Une substitution n’est publiable que si : x est complet, l’EU passe le LLM Judge, la source primaire est traçable, la boundary est explicite, l’offre/capability est cohérente et l’XPath cible exactement un élément DOM.
